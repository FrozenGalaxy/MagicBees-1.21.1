# Magic Bees

NeoForge 1.21.1 version of Magic Bees.

Optional mod support: Forestry, Thaumaturge (Thaumcraft), Thermal Series, Botania, Applied Energistics 2, ProjectE, Railcraft Reborn, Ars Nouveau

Original mod: Magic Bees 1.12.2 by MysteriousAges and contributors, specifically MagicBees-1.12.2-3.2.25.jar on CurseForge: https://www.curseforge.com/minecraft/mc-mods/magic-bees
